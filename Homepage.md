# About

## About / Beyond Work

The About section should introduce personality without making the portfolio feel like a personal blog or Instagram page.

### Overall concept: Contact Sheet

Use a **contact-sheet-inspired photo grid** rather than a conventional card layout.

The section should feel like a curated collection of snapshots, while still following the site's overall connected-grid visual language.

The layout should use a combination of different image sizes/aspect ratios to create a slightly asymmetric collage within the grid. Images should share borders with adjacent cells rather than appearing as floating cards.

Example structure:

```text
┌──────────────────────────────────────────────────────────────┐
│ // ABOUT_01                                                  │
├───────────────────────────────┬──────────────────────────────┤
│                               │                              │
│  A LITTLE ABOUT ME            │       ┌──────────────┐       │
│                               │       │              │       │
│  Short personal introduction  │       │    PHOTO     │       │
│  about Clarissa's background  │       │              │       │
│  and interests.               │       └──────────────┘       │
│                               │                              │
│                               ├──────────────────────────────┤
│                               │                              │
│                               │  ┌─────────────┐ ┌────────┐ │
│                               │  │             │ │        │ │
│                               │  │    PHOTO    │ │ PHOTO  │ │
│                               │  │             │ │        │ │
│                               │  └─────────────┘ └────────┘ │
│                               │                              │
└───────────────────────────────┴──────────────────────────────┘
```

The exact arrangement can change responsively, but it should retain the feeling of a **contact sheet / curated collection of photographs**.

### Images

Use approximately 3–5 images representing personal interests or experiences.

Possible categories:

* Dance / choreography
* Cooking
* Travel
* Creative projects
* Everyday life / NYC

Do not use generic stock photography. The images should eventually be replaced with Clarissa's own photos.

Each image should have a small metadata-style label, such as:

```text
// DANCE_01
Choreography
```

```text
// TRAVEL_01
New York
```

```text
// COOKING_01
Currently experimenting
```

### Hover interaction

The hover interaction should be **subtle and contained**.

Do NOT make the entire grid rearrange when hovering.

Do NOT make neighboring images move, resize, or reflow.

Do NOT use a complicated masonry animation.

Instead, each individual image should independently respond to hover.

#### Default state

Show:

* Image
* Minimal or no caption
* Thin grid border
* Natural image crop

#### Hover state

When the cursor enters an image:

1. Slightly enlarge the image using a very small scale transform, approximately `scale(1.03)`.
2. Keep the image contained within its existing grid cell.
3. Reveal a small caption/metadata overlay.
4. Slightly increase the visual prominence of the cell.
5. Optionally change the cell border to the burgundy accent color.
6. Use a short, smooth transition around `200–300ms`.

The important behavior is:

```text
NORMAL

┌─────────────────────┐
│                     │
│       PHOTO         │
│                     │
│                     │
└─────────────────────┘


                    ↓ hover


HOVER

┌─────────────────────┐
│                     │
│     PHOTO           │
│        slightly     │
│        enlarged     │
│                     │
├─────────────────────┤
│ // DANCE_01         │
│ Choreography        │
└─────────────────────┘
```

The image should **visually enlarge within its existing cell**, not cause the grid layout to change.

Use `overflow: hidden` on the image container so the scale effect remains contained inside the cell.

Suggested implementation:

```css
.about-image {
  overflow: hidden;
  position: relative;
}

.about-image img {
  transition: transform 250ms ease;
}

.about-image:hover img {
  transform: scale(1.03);
}
```

The caption can transition from slightly transparent/hidden to visible:

```css
.about-caption {
  opacity: 0;
  transform: translateY(4px);
  transition: opacity 200ms ease, transform 200ms ease;
}

.about-image:hover .about-caption {
  opacity: 1;
  transform: translateY(0);
}
```

### Caption styling

Keep captions consistent with the site's technical visual language.

Use:

* Monospace font for the category label
* Small uppercase text
* Near-black or burgundy text
* Simple background
* No rounded pill/container styling

Example:

```text
// DANCE_01
Choreography
```

The caption should feel like **metadata attached to a photograph**, not a social-media caption.

### Mobile behavior

There is no hover interaction on touch devices.

On mobile:

* Keep the contact-sheet grid
* Keep captions visible or reveal them through tap/focus
* Do not require hover to understand the image
* Preserve the connected-border aesthetic
* Allow the grid to collapse into 1–2 columns depending on screen width

The About section should remain visually interesting even without interaction.

### Personality level

This is the section where the portfolio can become slightly more playful and visually expressive.

However, keep the overall design restrained.

Target:

**80% professional / 20% personality**

The contact sheet should feel like a small glimpse into the person behind the resume, not a photography portfolio.
